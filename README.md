# Утренняя вкладка

Скилл для агентов (Claude Code, Codex и других с shell): каждое утро собирает газетную страницу с главным по вашей теме и публикует её по постоянной ссылке.

Это форк [smixs/morning-tab](https://github.com/smixs/morning-tab) с доработками: оценка значимости материалов, отбор по важности, прогноз погоды со значками, сайт из нескольких тем, мобильная вёрстка. Подробности — в разделе [«Что добавлено в форке»](#что-добавлено-в-форке).

## Что делает скилл

- **Любая тема.** При первом запуске агент спрашивает тему и источники или подбирает их сам: Google News, RSS сайтов, Hacker News, arXiv, YouTube, GitHub Trending.
- **Сбор и ранжирование.** `scripts/fetch.ts` забирает свежие материалы за окно `windowHours` (обычно 24 часа), убирает повторы и считает вес: бонус источника, ключевые слова темы, очки Hacker News, свежесть, наличие картинки.
- **Тексты пишет агент** на языке страницы: заголовки, краткие пересказы, вводный абзац к главной, «Главное за день». Факты — только из собранных материалов. Платных API нет.
- **Вёрстка в стиле газеты.** `scripts/render.ts` собирает одну HTML-страницу: главная и вторая новость, блок коротких, рубрики, дайджест, альманах с погодой. Затем снимает скриншоты, по которым агент проверяет страницу.
- **Проверка окружения перед каждым запуском**: Bun, браузер для скриншота, сеть, вход на хостинг. Если чего-то не хватает, агент говорит, что именно, и просит это настроить.
- **Публикация** на Vercel, Netlify, Cloudflare Pages или GitHub Pages.
- **Ежедневная рутина**: после первого выпуска агент предлагает ставить выпуск на расписание.

## Что добавлено в форке

Все доработки необязательные: без новых полей в конфиге и без ключа Jev скилл работает как исходный.

- **Оценка значимости (Jev).** Если в окружении есть `TYPESAFE_API_KEY`, каждый материал получает оценку 0–4 от «шума» до «события дня». Оценка добавляет до 120 к весу, поэтому в основном она и определяет порядок на странице. Ключ держите в `.env` и передавайте через `bun --env-file=.env`.
- **Отбор по важности.** Поля конфига темы:
  - `minJev` — убрать материалы с оценкой ниже порога;
  - `maxItems` — оставить не больше N самых весомых;
  - `keep` в источнике — сколько его лучших материалов гарантированно попадает в выпуск (например, `"keep": 3` для GitHub Trending).
- **Оценка в строке источника:** `NATURE · JEV 2.1 · 2D`.
- **Погода.** В альманахе прогноз на 5 дней (min…max). В строке даты и в прогнозе — однотонные значки по коду Open-Meteo: солнце, облачно, дождь, снег.
- **Фраза дня.** Поле `tagline` в `texts.json` заменяет подзаголовок на один выпуск.
- **Сайт из нескольких тем.** Поле `nav: [{title, href}]` выводит ссылки на соседние страницы. Темы можно выложить на один сайт подпапками.
- **Мобильная вёрстка** для экранов до 640px. `shot.cjs` дополнительно снимает мобильные скриншоты и проверяет, что страница не шире экрана.
- **Чистые страницы статей.** Если у материала в `items.json` есть поле `readerUrl` (например, страница Telegraph без рекламы, созданная внешним шагом), заголовок ведёт на неё, а рядом появляется ссылка «ОРИГИНАЛ».
- **Скриншоты через Node** (`scripts/shot.cjs`): под Bun на Windows запуск браузера зависает.

Фрагмент конфига темы с полями форка:

```json
{
  "minJev": 1,
  "maxItems": 30,
  "nav": [{ "title": "Наука", "href": "science/" }],
  "sources": [
    { "name": "GitHub Trending", "url": "https://github.com/trending?since=daily", "type": "github-trending", "section": "github", "limit": 8, "keep": 3 }
  ]
}
```

Тесты доработок: `bun test scripts` в папке скилла.

## Установка

```
npx skills add wrx74/morning-tab
```

Или скопируйте папку `skills/morning-tab` в папку скиллов агента (для Claude Code — `~/.claude/skills/`) и выполните в ней `bun install`.

Дальше скажите агенту: «сделай утреннюю вкладку про <тему>».
